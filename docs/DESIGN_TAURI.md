## 1. 設計の前提と方針

利用者は技術者であり、画面の仕事は **①現在値を確認する（接続 / 現在値）②設定・リマップ・マクロを編集する ③書き込む前に安全を確認する（右レール + 確認ダイアログ）** の 3 点に限る。

- **ウィンドウ・ズーム**: 初期 1280×800、最小 **900×620**、200% ズームで横スクロールを出さない。
- **言語**: 日本語が主、英語切替可。技術名（BLE / GATT / MTU / SHA-256）は訳さない。
- **アイコン**: 外部アイコンセットは導入せず、16px・1.5 stroke のインライン SVG 線画のみ（色は `chalk` または `compass-gold`）。
- **現行スタイル（Imported style: Hyperstudio）**: 参考元は [Refero Styles](https://styles.refero.design/style/8eb9c53e-d69c-497a-b640-610856cf3a60)（提携・推奨関係なし）。`obsidian #101010` / `carbon #080808` / `paper-ink #1a1a1a`、1px ヘアライン（`graphite #212121` / `iron #474747`）、文字（`chalk #f3f3f3` / `ash #c1c1c1` / `smoke #9c9c9c`）、主アクションの白ピル（`signal-white #ffffff`）、アイコン線 `compass-gold #6f6759`、ライブ状態 `pulse-green #98ff38`、危険枠 `danger #b42318`（1px）。**影・グラデーション・絵文字・写真・weight 500 以上を使わない**（全要素 weight 400、角丸は 4 / 8 / 99 / 9999 のみ）。
- **旧案 C からの置換経緯**: 初期設計では案 C「昼の作業台と夜のステージ」（ライト面 + ダークステージ + `--shadow-pop` + Noto Sans JP / Hack）を採用したが、2026-11-23 に Hyperstudio の暗色固定へ置換した。[design/mockup.html](design/mockup.html) は案 C 時代の経緯資料であり、現行実装とは一致しない。

## 2. レイアウトとブレークポイント

上部バー（52px）・左ナビ（216px）・コンテンツ（最大 1200px）・右レール（344px、最小 320px、`position: sticky`）の 4 領域で構成する。

- **上部バー**: 左にアプリ名と副題（書き込み実装前は **「開発版（画面骨格）」**、P3 以降は「書き込み対応版」）、右に状態（ドット + 状態名、画面全体で 1 か所のみ）・接続先名・言語切替・設定。
- **左ナビ**: デバイス / 入力モニター / 現在値 / 設定 / マクロ / ログ + 下部にライセンスと接続先要約（未接続時は「未接続」のみ、デバイス名をハードコードしない）。
- **右レール**: 全画面で「書き込み前の確認」を常設する（P3 までは変更なし・無効理由のプレースホルダ）。
- **ブレークポイント**:
  - **1180px 以上**: 左ナビ + コンテンツ + 右レール。
  - **900〜1179px**: 左ナビ + コンテンツ。右レールはコンテンツの下へ移動し全幅表示。表は幅 1100px 未満で「補足」「単位」列を隠し行展開で表示。
  - **900px 未満**: 非対応（`minWidth: 900`）。200% ズーム時は 1 列へ折り返すよう `rem` 基準で組む。
- **スクロール・重なり**: `html, body { height: 100dvh; }`、`overflow: hidden`、ナビとコンテンツのみ独立スクロール（`scrollbar-gutter: stable`、フレックス子要素に `min-width: 0`）。z-index は `0`（基本）/ `10`（sticky）/ `20`（ポップオーバー）/ `30`（トースト）/ `40`（オーバーレイ）/ `50`（ダイアログ）の 5 段。

## 3. コンポーネント仕様とアクセシビリティ

すべての部品に **default / hover / focus-visible / active / disabled / loading / error / empty** の 8 状態を定義する。色・角丸・枠線は [design/IMPORTED_STYLE_HYPERSTUDIO.md](design/IMPORTED_STYLE_HYPERSTUDIO.md) に従う。

| コンポーネント | 要点・アクセシビリティ |
| --- | --- |
| ボタン | 1 画面に主アクション（白ピル）1 つ。高 32px 以上。disabled は輪郭を消し **直上に理由を 1 行表示**。loading は左に 12px スピナーを置きラベルは変えない |
| 入力・数値 | `<label for>` 必須。数値は等幅・`inputmode="numeric"`・`min`/`max`/`step` 指定。プレースホルダーに例の値を書かずラベル下に範囲を表示。エラーは直下に `aria-describedby` |
| スイッチ | `<button role="switch" aria-checked>`（Space/Enter）。右側に「オン」「オフ」をテキスト表示（色だけに頼らない） |
| セレクト | ネイティブ `<select>`（自作リストボックス不可）。`background-color` と `color` を明示 |
| タブ | 設定画面のサブタブのみ（2 階層にしない）。`role="tablist"` / `tab` / `tabpanel`、← → Home End 操作 |
| テーブル | 数値列と見出しは右揃え・等幅。選択行は `paper-ink` 地 + 罫線。行クリックより行内の主操作ボタンへフォーカス |
| ダイアログ | ネイティブ `<dialog>` + `showModal()`（幅 480 / 確認 560、本文のみスクロール、初期フォーカスはキャンセル側、Esc で閉じる）。**書込確認の順序**: ①何をするか 1 文 ②変更点一覧（現在値 → 変更後）③バックアップ保存先 ④確認チェックボックス ⑤キャンセル / 書き込む。破壊的操作は対象名 + 「元に戻せません」を明記 |
| トースト | 右下、幅 280〜420、`aria-live="polite"`、最大 3 件、4 秒（danger 8 秒、hover/focus で停止）。1 文の通知は句点なし。「元に戻す」は取り消せる操作のみ |
| バナー・空状態 | バナーはコンテンツ上部 1 本。空状態は左揃えで「状態 1 文 + 見出し『次にすること』+ 行動 1 つ」。読込中は 3 行スケルトン |

- **ランドマーク・フォーカス**: `<header>` / `<nav aria-label="画面">` / `<main>` / `<aside aria-label="入力モニター">`、`aria-current="page"`、`:focus-visible` に `outline: 1px solid var(--chalk)`、`color-scheme: dark`。
- **ライセンスダイアログ**: 現状は `MIT OR Apache-2.0` と P6 注記のみ表示。P6 でフォント同梱時にアプリ＋同梱フォント全文・著作権者行を表示する。

## 4. 入力モニターの描画仕様

入力レポート（`cmd=0x0003`、12B。[PROTOCOL_SPEC.md](PROTOCOL_SPEC.md) §7.2）を描画する。

| フィールド | 生値 | 正規化・表示 |
| --- | --- | --- |
| `LeftStick_X/Y`・`RightStick_X/Y` | u8（中心 127/128） | `n = clamp((raw - 127) / 127, -1, +1)`。`x = cx + nx * r`, `y = cy - ny * r` |
| `Trigger_R`・`Trigger_L` | u8（0〜255） | `t = raw / 255`（0〜1）。横バー（高 6px）+ 等幅数値 |
| `Battery` | u8（**スケール未確認**） | % 換算せず生値のまま表示 |

- **Y 軸の向き（未確認）**: 生値の Y 上方向が + か − か実機未確認のため、アダプタ層に定数 `Y_SIGN: +1 | -1` を 1 か所だけ置き、実機確認後に固定する（コンポーネント側で二重反転しない）。
- **描画要素**: スティック円（径 160px、デッドゾーン破線円、現在点径 10px、軌跡は実機接続後直近 8 点を α 0.35→0.02 で描画し静止時は消す）、トリガー横バー L2/R2、押下ボタンはテキストチップ（コントローラ線画は描かない）。
- **60fps と補間**: BLE 20ms 通知を `useRef` + `requestAnimationFrame` で canvas 描画し、React 再レンダーを毎フレーム起こさない。補間 `s = 1 - exp(-dt / τ)`（スティック τ=45ms、トリガー τ=60ms）、数値表示は 10Hz（100ms）更新、ボタンは補間なし（最低 1 フレーム点灯）。500ms 無受信で注意表示、2 秒で切断・停止扱い。1 フレーム予算 4ms を超えたら軌跡を 8→4 点へ自動削減。
- **a11y・reduce-motion**: canvas は `aria-hidden="true"`、数値は DOM テキスト、`P` キーで一時停止、「現在の値を読み上げる」ボタンで `aria-live="polite"` 要約出力。`prefers-reduced-motion: reduce` では補間と軌跡を無効化してスナップ表示。

## 5. モーションと応答性

- **時間と曲線**: `--dur-0: 0ms` / `--dur-1: 90ms`（hover・押下）/ `--dur-2: 160ms`（タブ・スイッチ）/ `--dur-3: 240ms`（ダイアログ・トースト）、`--ease-standard: cubic-bezier(0.2, 0, 0, 1)`、`--ease-linear: linear`。`transform` / `opacity` / `background-color` / `border-color` のみ動かし、`transition: all` は禁止。`prefers-reduced-motion: reduce` で時間を 0ms にし点滅を止める。
- **応答しない問題への 3 段階**: 0ms 即時 `:active` → 100ms 以内にボタン直下へ進行行（「書き込みを準備しています…」）→ 400ms で「応答を待っています…」+ 経過時間 → 2 秒で「中止する」提示 → タイムアウト時は操作近傍にエラー + 再試行 + 詳細折りたたみ。
- **書き込み中・切断**: 書き込み中はナビ移動を許可しつつ編集・書込をロックし上部バーに「書き込み中」を表示。切断は fail-closed で操作無効化 + 上部バナーに再接続案内。

## 6. 日本語コピー規約と用語集（正本）

- **文体**: 本文・説明・エラーは「です・ます」（句点あり）。ラベル・見出し・ボタン・1 文のトーストは体言止めまたは動詞句（句点なし）。手順は「〜します」、依頼は「〜してください」。進行中は「〜しています…」（三点リーダ 1 つ）。1・2 人称、感嘆符、日本語 UI 内のコロン、バッククォートは使わない。
- **表記**: 括弧は全角「（）」（コード・パスは半角）、数字は半角、和文と英数字の間は半角スペース 1 つ、単位は半角スペース区切り（`2768 バイト`、`20 ms`）、16 進は `0x` + 大文字、範囲は `0〜127`。ボタンは 12 文字以内、説明文は 40〜80 文字。エラーは「何が起きたか → 理由 → 次にすること」の順。
